# Support

For usage questions, start with the [README](README.md) and [documentation](docs/). If the question is not a bug or feature request, open a GitHub Discussion when Discussions are enabled.

Use GitHub Issues for reproducible defects and scoped feature proposals. Use private vulnerability reporting for security concerns; see [SECURITY.md](SECURITY.md).

Please do not post real indexes, local filesystem layouts, credentials, or resource contents in support requests.
